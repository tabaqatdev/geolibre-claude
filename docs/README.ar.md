# 🗺️ GeoLibre-Claude — دليل البدء السريع

> اجعل Claude هو **العقل المُدبِّر** لأعمالك الجغرافية المكانية على نمط [GeoLibre](https://geolibre.app):
> استكشاف كتالوج البيانات، والاستعلام بلغة DuckDB المكانية، والترميز اللوني، والمعالجة الجغرافية،
> والتحكم في الخريطة الحية — بـ ١٦ لغة، وبرخصة MIT مفتوحة المصدر.

هذه ترجمة مختصرة لملف [README](../README.md) الإنجليزي. للتفاصيل الكاملة والخطة، انظر
[README.md](../README.md) و[ROADMAP.md](../ROADMAP.md).

## الفكرة

يُضمِّن GeoLibre نموذجًا لغويًا *داخل* التطبيق. أما هنا فنعكس البنية: يصبح **Claude هو المُضيف ومحرّك
الاستدلال**، وتُعرَّض قدرات GeoLibre وكتالوج بياناتك له عبر **أدوات MCP** ومجموعة من **المهارات**.

المبدأ الحاكم — **أدوات رفيعة ومهارات غنية**: يحمل الخادم فقط عمليات بدائية آمنة، وكل الذكاء (بناء
الاستعلام، الترميز، المعالجة، التعدد اللغوي) يعيش في المهارات.

## المتطلبات

- **Rust** (نسخة مستقرة ≥ 1.82) — <https://rustup.rs>
- **Node.js** ≥ 18 (لإضافة GeoLibre)
- **mkcert** (فقط لمسار HTTPS + OAuth)
- **GeoLibre سطح المكتب** (فقط للتحكم في الخريطة الحية)

## البناء والتشغيل

```bash
git clone https://github.com/tabaqat/geolibre-claude
cd geolibre-claude
cp .env.example .env          # ثم اضبط GEOLIBRE_CATALOG_URL
./start.sh                    # يبني كل الشيفرة، ويجهّز الشهادات، ويثبّت الإضافة
```

على ويندوز (PowerShell): استخدم `./start.ps1`.

## ربط Claude

```bash
claude mcp add geolibre-claude -- "$(pwd)/target/release/geolibre-claude" --transport stdio
```

ثم اسأل بالعربية، مثلًا: «كم عدد المدن التي يزيد عدد سكانها عن ٥ ملايين؟» — يتولّى الأداة `normalize_query`
توحيد الحروف والأرقام، وتبحث `search_catalog` عن الطبقة المناسبة، ويأتي الرد بالعربية ومن اليمين لليسار.

## اللغات

يدعم GeoLibre-Claude لغات GeoLibre الست عشرة جميعها، مع الرجوع إلى الإنجليزية عند غياب الترجمة:
العربية · English · 中文 · Español · Français · Deutsch · Português · Italiano · Nederlands · 日本語 ·
한국어 · Русский · Türkçe · Indonesia · हिन्दी · ไทย.

المعالجة الأعمق للعربية: توحيد الألف والهمزة (آأإٱ ← ا)، وإسقاط التشكيل والتطويل، وتحويل التاء المربوطة
(ة ← ه) والألف المقصورة (ى ← ي)، وتحويل الأرقام العربية-الهندية (٠-٩ ← 0-9).
