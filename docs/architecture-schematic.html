GeoLibre-Claude

A public Claude Code plugin that flips the topology: Claude becomes the host and reasoning engine, while GeoLibre's capabilities and your data catalog are exposed as MCP tools plus multilingual skills.

Guiding principle — thin tools, thick skills: the server holds only dumb, safe primitives; all intelligence lives in skills. Built in Rust to match GeoLibre — reusing its own crates rather than reimplementing them.

Stack Rust (rmcp · duckdb-rs) + TS plugin · Transport stdio | HTTPS :8443 (mkcert + OAuth) · 16 locales · Owner Tabaqat · Updated 2026-08-10

01  Runtime topology

data / read path — always available app / control path — needs running GeoLibre fallback channel

02  Division of labor

deterministic · rust

MCP tools — thin

  • rmcp · single Rust binary, no reasoning
  • spatial_sql SELECT-only via duckdb-rs
  • Geo tools reuse geolibre-rust
  • App-bridge: add_layer · set_style · zoom_to
  • Small, auditable, portable
intelligence

Skills — thick

  • Choose layers · write spatial SQL
  • Design ramps · chain geoprocessing
  • 16 locales · Arabic normalization + RTL
  • Earth observation (STAC / Sentinel)
  • Agents orchestrate; commands enter

03  Milestones

Phase 02–3 days

Foundations & verification

Confirm the GeoLibre plugin API (socket? map + DuckDB-WASM? tool registration?), size the catalog, scaffold the repo skeleton.

Accept: claude --plugin-dir . loads the stub; namespaced skills appear in /help.

Phase 11–2 weeksv0.1 · first usable

Data MCP + core skills

Data tools over stdio; skills geolibre / catalog / spatial-sql; agents catalog-scout & spatial-sql-writer.

Accept: ask a data question in English → correct answer + table from the live catalog.

Phase 21 weekv0.2

Multilingual + semantic catalog

catalog index (BM25 + alias, optional embeddings); search_catalog + normalize_query; geolibre-i18n skill & language-liaison agent.

Accept: the same question in Arabic (spot-checked in ≥2 more locales) resolves to the right layer and replies in-language (RTL for Arabic).

Phase 31 weekv0.3

Visualization skills

Symbology, geoprocessing, earth-observation skills; symbology-designer agent.

Accept: "buffer schools by 500 m, color by capacity" → correct SQL + symbology spec.

Phase 41–2 weeksv0.4 · full parity

Live app control

geolibre-claude-bridge (GeoLibre TS plugin) + app-bridge tools; map-control & project-file skills; /map and /analyze commands.

Accept: Claude adds a styled layer to a running map and zooms to it.

Phase 5ongoingv1.0

Release hardening

Localized docs + examples; plugin validate; marketplace listing; HTTPS+OAuth deployment guide (mkcert + IdP).

Accept: a fresh clone reaches working v0.1 in under 10 min from the README.
